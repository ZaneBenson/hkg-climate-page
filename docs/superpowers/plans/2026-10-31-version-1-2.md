**Goal:** Version 1.2.0 as designed after the first 1.1.0 car run: presets that land reliably (spacing and retries), no crash on Save, scrollable dropdowns, driver and passenger temperatures, an applied-preset highlight, six presets, the owner's panel redesign (gear, mode icons, swap/× sub-buttons), settings that survive NEMESIS updates, and a settings app that fits beside the side panel.

The panel page is redrawn and the panel patch rebuilt. The package hooks keep the app's settings across an update.

## Global Constraints

- **Commands:** only the approved ones (seats 2..8; DATC flag/value list; wheel press 1 then 0 after 200 ms; eco 2/1). The × sends seat value 2. Swap sends nothing. `CheckedCabinSender` and `CheckedSeatSender` allowlists are unchanged.
- **Spacing:** `COMMAND_GAP_MS` = 400 between any two runner commands; the runner's first command at least 400 ms after the tap's seat sends; after each gap, re-read, then decide.
- **Retries:** temperature and fan steps only, not forced presses: if the stepped value hasn't changed `RETRY_WAIT_MS` = 500 after a press, re-read and press again, at most `MAX_RETRIES` = 2 per step, every press counted toward the item's cap (fan 10, temperature 25). No retry for climate off, auto, A/C, airflow, sync, wheel, eco.
- **Presets:** `PresetList.MAX` = 6. `Preset` replaces `tempF` with `driverTempF` and `passengerTempF` (each LEAVE or 62..82). Sync "on" stores the passenger temperature as LEAVE. Line format: 12 fields (name, driver, passenger, wheel, eco, climate, driverTempF, passengerTempF, fan, ac, airflow, sync); 3- and 11-field lines still load (an 11-field temperature → both sides, except passenger LEAVE when that line's sync is on).
- **Highlight:** only the last tapped preset; in effect from the tap, during the run, and while every item that reached its target still reads at it; items left alone by design or reported not done don't count; seat state gets `SEAT_GRACE_MS` = 3000 after the tap; a tap that needed no commands still highlights; editing/deleting/reordering presets, another preset tap, or an app restart clears it. After the run the app re-reads cabin, wheel and eco every `HIGHLIGHT_POLL_MS` = 2000 while a page is subscribed.
- **Swap/×:** swap flips the seat's next-tap mode while it stays off (not offered on a heat-only seat); the flip ends when the seat turns on (and the automatic choice returns when it next goes off). × sends 2 for an on seat, with the same gates as a seat tap.
- **Page:** layout and colours per the spec's "The panel" section and the mockup: gear button 44 × 44 dp (icon 26 dp), top line 384 dp wide; seat icon 56 dp tall at the outer side aligned with the outer bar (passenger mirrored; heat-mode arrows, cool-mode fan, plain when unavailable); 52 dp round sub-button 14 dp from the top and inner edges; no seat names or state text; presets 180 × 50 dp, two per row, up to three rows, only saved ones drawn; highlight = 4 dp border, bold name, colour #FFFFFF at night / #1F2A30 by day, fill = text colour at alpha 0x2E (~18 %).
- **Link:** `TX_SEAT_SWAP` = FIRST_CALL_TRANSACTION + 4 (in: int seat, long requestId; oneway), `TX_SEAT_OFF` = + 5 (same). Keys: `K_PRESET_ACTIVE` (int, slot index or -1), `K_SEAT_SWAP` (boolean[]: sub-button shows swap), `K_SEAT_OFF` (boolean[]: sub-button shows ×). Preset arrays are length 6. Same uid checks as the existing transactions.
- **Settings screens:** one column ≤ 800 dp wide, left-aligned, 24 dp padding; dialogs no wider than the column; Spinners in dialog mode (`Spinner.MODE_DIALOG`).
- **App manifest:** `<uses-permission android:name="android.permission.GET_TASKS" />`; version 1.2.0, versionCode 6 (manifest, build-app defaults, check-app, NEMESIS.data).
- **Hooks:** preuninstall copies `/data/data/hkgclimate.app/shared_prefs/hkgclimate.xml` to `/data/nemesis/hkg.climate.page.settings.xml`; postinstall restores it before starting the service, only if the app has no settings file, with the app's owner (taken from its data directory) and mode 660; failures are logged and never fail the hook. Shell rules: no printf/tail/head/seq/`[[ ]]`.
- **Page safety:** every page entry point catches Throwable; no `com.hkmc` reference in the page.
- Commits: plain words, ending `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`. No session links.

## Review Focus

1. **A dropped step:** a temperature press the car ignores is re-sent after 500 ms, at most twice, and the step then stops with "no change"; a press that lands is never repeated. Test in Task 1.
2. **Highlight flicker:** a seat-only preset doesn't lose its highlight in the first 3 s while the seat listener catches up; a run with a skipped passenger (sync) keeps the highlight. Test in Task 3.
3. **Old saved presets** (3- and 11-field) load into the 12-field model without changing any seat or temperature. Test in Task 2.
4. **An update with settings to keep:** preuninstall copies the file; postinstall restores it only when the app has none, with the right owner; a missing source file or a failed copy logs and continues. Test in Task 7 (package mock).
5. **Swap on a heat-only seat or while a preset runs:** nothing changes, nothing is sent. Test in Task 3.
