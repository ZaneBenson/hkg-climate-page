# Version 1: on-car checklist

Version 1 (1.0.0) applies your layout changes: the top line shows only the outside
temperature, each seat button's border shows what the next tap does, there is no test strip,
and there is no approval switch. Taps send the approved seat command, one step per tap.
Package: `dist/hkg-climate-usb.zip` (recommended: the package and the kit on one stick; see
its `README-USB.txt`). Only US firmware 260507 is supported.

Test build 2 is on the car, and this build installs over it. Have the car on (ready to
drive) for the seat tests. Please note anything odd, even if it seems small.

## Steps

1. Install from the combined stick. If the install says there isn't enough space on /system,
   restart the head unit and plug the stick in again (the update has to finish removing test
   build 2 first).
2. The page fits: both seat buttons and both preset columns are fully inside the panel.
3. The top line shows only the outside temperature.
4. With both seats off, the borders are orange below the switch temperature and blue at or
   above it (change the switch temperature in settings to see both).
5. Taps change the seats right away, with no approval needed. A seat that's on keeps its
   border colour until it's back off.
6. The settings screen has no "Send seat commands" switch.
7. Right after the tap steps, and before you restart, run the kit from Manager ("Run USB
   NEMESIS.sh" on the combined stick). The kit keeps only about the last minute of the
   Android log, and a restart wipes it. Send the `HKGCLIMATE` folder.
8. Restart: nothing changes by itself. Run the kit again after the restart only if
   something was odd, and send that folder too.

## If something goes wrong

- The settings screen's "Seat command" line says `no change after 3 s` and the car isn't on
  (ready to drive): this is expected. Turn the car on and tap again.
- A tap does nothing, or the "Seat command" line says `no change after 3 s` with the car on,
  or says `send failed`: stop tapping, run the kit right away and send the folder.
- The right-hand screen goes blank or keeps restarting: uninstall HKG Climate Page in NEMESIS
  (it puts the original panel files back), then restart the unit.
- A message says the install could not be fully undone: do not restart the unit. Look at the
  NEMESIS log and tell us what it says.
