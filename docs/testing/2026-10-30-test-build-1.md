# Test build 1: on-car checklist

This build adds a climate page to the right-hand screen. **It never changes the seats.**
Tapping a seat button only writes a line to a log. Please do the steps in order and write
down anything odd, even if it seems small. Package: `dist/hkg-climate-page.zip`.

## Before you install

- Back up `private/keys/hkgclimate.jks` and `private/keys/password`. Later updates must be
  signed with the same key, so if they are lost the app has to be uninstalled first. Keep these private; never send them.
- The install needs about 344 MB free on the unit's data storage and about 180 MB on the
  system storage. It checks first and refuses (changing nothing) if there is not enough.
  The exact figures are in `/data/nemesis/hkg.climate.page.log`, on the "free space" line.
- Only US firmware 260507 is supported. Anything else is refused with a message.

## Steps

1. Put the zip on the USB drive and install it with NEMESIS. The unit restarts. Keep the
   USB drive in until it says to remove it.
2. After the restart, swipe the right-hand screen. The climate page should be **one swipe
   after the first page**. Note: does the right screen start at all, or is it blank?
3. The top line should match the car's outside temperature.
4. The seat buttons should match what the seats are doing now.
5. Change a seat with the touch strip. The page should follow within about a second.
6. Tap each seat button a few times. **Nothing should change in the car.**
7. Tap the gear to open the settings screen. Write down:
   - the seat **option** numbers (expected: 6 for both seats),
   - the temperature unit (expected: 2),
   - the "Page lists:" line: does it say `ok`, or show an error?
8. Change the switch temperature. The top line's "taps will heat/cool" should follow.
9. Restart the unit. The page should still be there.
10. Right after the taps (the kit only keeps about the last minute of the Android log), run
    the hkg-climate kit and send back the `HKGCLIMATE` folder. Also send the install log,
    `/data/nemesis/hkg.climate.page.log`. If the kit does not include it and NEMESIS has
    no way to copy it, just tell us and we will add it to the kit.
11. Uninstall HKG Climate Page in NEMESIS and restart. The right-hand screen should work as
    it did before.

## What we expect to see in the log

These lines are in the Android log (logcat), tag `HkgClimate`. The kit saves it as
`logcat-full.txt` in the `HKGCLIMATE` folder. It covers only about the last minute, so run
the kit right after the taps.

For every seat tap, one line:

- `would set setFrontSeatHeatDrvStep <v>` for the driver seat
- `would set setFrontSeatHeatAstStep <v>` for the passenger seat

with `<v>` one of 2, 3, 4, 5, 6, 7, 8. Also in `logcat-full.txt`, there should be no `FATAL`
line from `com.mobis.splitscreen.right`. The file `/data/nemesis/hkg.climate.page.log` is
different: it is only the install and uninstall log.

## Things only the car can show

Please say yes or no to each:

- Does the patched right screen start at all? (Android may refuse the patched file.)
- Does the page show up after one swipe?
- Does the "Page lists:" line show an error? (The app needs permission to change system
  settings, and this firmware may not allow it.)
- Are the seat options 6 and the unit 2?
- Does a **second** climate-looking page appear, or do log lines from `SplitScreenClimateView`
  show up? The stock screen has its own hidden climate page that uses the same slot (id 4).
  Ours should be the one you see, but the car has to confirm it.
- Any shell error in `/data/nemesis/hkg.climate.page.log`? The install scripts have only
  been run on the PC, not on the unit's own shell.

## If something goes wrong

- The right-hand screen goes blank or keeps restarting: uninstall HKG Climate Page in
  NEMESIS (it puts the original panel files back), then restart the unit.
- A message says the install failed and the panel was restored to stock: the car is back to
  normal, but uninstall HKG Climate Page in NEMESIS too, so it can be tried again cleanly.
- A message says the install could not be fully undone: do **not** restart the unit.
  Look at the NEMESIS log and tell us what it says.
- The page doesn't appear after a restart: open the Climate Page app from the app list once,
  then swipe again.
